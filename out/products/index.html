Chrome extension

Culprit

Every failure leaves a clue.

Culprit is our proprietary Chrome extension for software debugging. It records what happened in the browser, ties each failed request back to the click that caused it, and turns that into a selector, a reproduction and a bug report you can paste straight into a ticket.

Available on the Chrome Web Store

Open source

TerminalQuest

Learn the terminal by saving a ship — not by reading slides.

A small arcade game that teaches the command line by making you use it. Each station drops you into a real bash prompt: what you type actually runs, and a real file has to move before anything unlocks. Open source, free to play and fork.

  • 8 commands, 3 levels
  • 502 automated tests
  • 98% coverage
  • Zero dependencies
  • MIT
